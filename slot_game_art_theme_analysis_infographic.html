2. Color Palette Psychology & Visual UI Hierarchy

Strategic Palette Choices for Emotional Triggers and Mobile Layout Ergonomics

Color palettes are strategically leveraged to trigger specific emotional responses: warm gold and crimson red evoke feelings of wealth and high arousal, while cooler tones balance visual clutter. Visual hierarchy directs user focus to high-value symbols using scale, dynamic lighting, and 3D motion FX.

Visual Hierarchy in Mobile UI Layouts

⭐ Special & High-Pay Symbols

Built with 3D embossing, metallic gold textures, and prominent outer glow FX for immediate visual focus.

🃏 Low-Pay Symbols (A, K, Q, J, 10)

Styled with clean flat vector art, matching theme colorways with reduced detail to avoid visual distraction.
